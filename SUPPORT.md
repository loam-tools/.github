# Support

Use the affected repository's issue tracker for reproducible bugs and engineering tasks.

When reporting a problem, include the smallest useful reproduction. For WAYLOAM routing issues, include the origin, destination, selected routing profile, app/router version and the exact error shown. Do not include private addresses or location history unless they are necessary and safe to share in that repository.

For release/update issues, include the installed version and the version being offered. Never post signing keys, access tokens or credentials.

Loam Tools projects are under active development; alpha behavior may change between releases.
